# 📚 Article Management System (ASP.NET)

Bu proje, akademik ve genel makalelerin **PDF / HTML formatlarında saklanması, görüntülenmesi ve yönetilmesi** amacıyla geliştirilmiş web tabanlı bir **Makale Takip Sistemi**dir.

Kullanıcılar, ilgi alanlarına göre makale araması yapabilir, makaleleri kişisel kütüphanelerine ekleyebilir, okuma durumlarını takip edebilir ve makaleler üzerine notlar alabilir.

---

## 🚀 Temel Özellikler
- Makale arama ve listeleme
- Kişisel makale kütüphanesi oluşturma
- Okuma durumu takibi ve not alma
- Anahtar kelimelere dayalı makale önerileri
- Güvenli makale görüntüleme (`.ashx` handler)
- Oturum (Session) tabanlı kullanıcı yönetimi

---

## 🛠 Kullanılan Teknolojiler
- **C# / ASP.NET Web Forms**
- **.NET Framework**
- **MSSQL**
- **JavaScript, HTML, CSS**
- **Crossref API**
- **ASP.NET Web API + Swagger**
